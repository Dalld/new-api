# 推荐计划与渠道状态中文化及 UI 合并设计

## 目标

在不改变返佣结算、探针任务、API 和数据库结构的前提下：

1. 保留 `new-api-deploy.tar.gz` 中用户推荐计划页的黑金渐变邀请卡 UI。
2. 保留当前分支已经完善的 URL 搜索状态、分页、错误处理、响应校验和移动端列表。
3. 推荐计划与探针相关界面跟随系统语言；简体中文和繁体中文环境不得出现未翻译英文。
4. 在首页公共导航中增加 `/status` 入口，中文名称为“渠道状态”。
5. 形成可直接用于生产环境的源码归档、校验值、迁移说明、部署及回滚步骤。

## UI 合并

`web/src/features/my-affiliate/index.tsx` 继续使用当前分支的数据查询、路由搜索参数和响应模型。页面顶部邀请区域恢复压缩包版本的黑金渐变视觉，展示邀请链接、复制操作、邀请人数和累计返利。表格、移动端卡片、搜索与分页保持当前实现。

管理端返佣页和钱包推荐计划卡不使用旧文件整体覆盖；仅补齐翻译，避免丢失当前分支的字段、移动端适配及异常状态。

## 国际化

组件继续以英文源键调用 `t()`，不硬编码中文。补齐 `web/src/i18n/locales/zh.json` 和 `zh-TW.json` 中以下范围：

- 用户推荐计划、管理员返佣管理和返佣设置。
- 探针设置、手动运行、结果列表及所有校验/错误状态。
- 公开渠道状态页的标题、说明、健康状态、时间线、空状态及错误状态。
- 首页导航中的 `Channel Status`，简体中文显示“渠道状态”。

其他语言保持英文回退或其现有翻译，页面语言仍由系统语言选择控制。

## 公共导航

通过现有公共导航链接模型加入 `/status`。入口在桌面导航和移动菜单中同时可见，不依赖登录状态，不改变管理端侧栏权限配置。英文名称为 `Channel Status`，中文由 i18n 资源翻译。

## 测试与验收

- 增加简体中文资源完整性测试，验证关键推荐计划、探针和导航键存在且不等于英文源键。
- 保留现有 API、组件、路由和侧栏测试。
- 运行前端测试、`bun run typecheck` 和生产构建。
- 在测试服务器重新构建镜像并滚动更新，数据库只执行应用自身的幂等迁移，不重新导入备份。
- 浏览器验收首页桌面/窄屏导航、用户推荐计划页以及 `/status`，确认中文文案、黑金邀请卡和三组探针均正常显示。

## 发布与回滚

交付当前提交范围、源码归档 SHA256、镜像标签与镜像 ID、数据库迁移清单、部署命令、验收命令和上一镜像回滚命令。生产更新不得覆盖 `.env`、MySQL 数据目录或现有 Docker 网络。
